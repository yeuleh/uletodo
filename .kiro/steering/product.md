# Product Overview

## uletodo - Modern Cross-Platform Todo Application

uletodo is a modern, cross-platform desktop todo application built with Tauri + TypeScript + React + Rust, designed for personal task management with a focus on simplicity, efficiency, and extensibility.

## Key Features

- **Task Management**: Create, edit, delete tasks with rich metadata including priorities, due dates, and project organization
- **Project Organization**: Multi-project support with grouping and tagging capabilities
- **Dual Time Modes**: Calendar scheduling (start/end times) and deadline-based tasks
- **Multiple Views**: List view, enhanced table view, Gantt chart, and dashboard analytics
- **Smart Filtering**: Built-in filters (today, this week, overdue) and custom filter creation
- **Cross-platform**: Native support for macOS (primary), Windows, and future Linux support
- **Data Sync**: iCloud Drive synchronization with conflict resolution
- **Multilingual**: English (default), Chinese Simplified, and Japanese support

## Design Philosophy

- Modern minimalist UI inspired by Things 3 and Todoist
- Personal productivity focus with extensible architecture for future collaboration features
- Local-first data approach with user-controlled synchronization
- Cross-platform consistency while respecting native OS conventions

## Target Users

Individual users seeking a powerful yet simple task management solution with:
- Project-based task organization needs
- Cross-device synchronization requirements
- Preference for native desktop applications over web-based solutions
- Need for both simple task lists and advanced project management views
