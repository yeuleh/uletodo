# uletodo

A modern, cross-platform desktop todo application built with Tauri + TypeScript + React + Rust.

## Overview

uletodo is designed for personal task management with a focus on simplicity, efficiency, and extensibility. It features a clean, modern interface inspired by Things 3 and Todoist, with powerful project management capabilities.

## Key Features

- **Task Management**: Create, edit, delete tasks with rich metadata
- **Project Organization**: Multi-project support with grouping and tagging
- **Dual Time Modes**: Calendar scheduling and deadline-based tasks
- **Multiple Views**: List, enhanced table, Gantt chart, and dashboard views
- **Smart Filtering**: Built-in and custom filters for task organization
- **Cross-platform**: Native macOS and Windows support
- **Data Sync**: iCloud Drive synchronization support
- **Multilingual**: English, Chinese, and Japanese support
