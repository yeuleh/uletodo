## 1. 项目概述

### 1.1 项目愿景
uletodo 是一个跨平台的桌面客户端待办事项应用程序，旨在为个人用户提供强大而简洁的任务管理解决方案，同时为将来的协作功能扩展预留设计空间。

### 1.2 技术栈
- **前端**: TypeScript + React + Vite
- **后端**: Rust
- **桌面框架**: Tauri
- **数据存储**: SQLite (分层存储架构)
- **目标平台**: macOS (优先) → Windows → Linux

### 1.3 设计理念
- 现代简约风格，参考 Things 3、Todoist 的设计理念
- 个人效率优先，专注核心任务管理功能
- 跨平台一致性体验
- 数据本地优先，用户完全控制

## 2. 术语定义

| 术语 | 定义 |
|------|------|
| 任务 | 用户创建的待办事项，包含标题、描述、截止日期等属性 |
| 子任务 | 隶属于主任务的子级任务，支持层级结构 |
| 项目 | 任务的逻辑分组，用于组织相关任务 |
| 分组 | 项目内的任务分类方式 |
| 标签 | 跨项目的任务标记系统，支持多标签 |
| 优先级 | 任务重要程度标记 (高/中/低) |
| 日历模式 | 设置开始时间和结束时间的具体时间段任务 |
| 截止日期模式 | 仅设置截止时间的任务 |
| 热数据 | 3个月内的活跃数据，存储在主数据库 |
| 冷数据 | 超过3个月的历史数据，存储在归档数据库 |
| 本地用户 | 应用内的用户身份，不依赖网络账号 |

## 3. 功能需求

### 3.1 核心任务管理

#### 3.1.1 基础 CRUD 操作
- **创建任务**: 支持快速创建和详细创建两种模式
- **查看任务**: 多种视图展示任务信息
- **编辑任务**: 内联编辑和详情编辑
- **删除任务**: 软删除机制，支持恢复

#### 3.1.2 任务属性
- **基本信息**: 标题、描述、备注
- **时间管理**: 
  - 日历模式：开始时间 + 结束时间
  - 截止日期模式：截止时间
- **分类信息**: 项目归属、分组、多标签
- **状态管理**: 优先级、完成状态、进度
- **协作字段**: assignee (分配者，为将来协作功能预留)

#### 3.1.3 层级结构
- **子任务**: 支持多层级子任务
- **任务依赖**: 基础的前后置关系
- **批量操作**: 选择多个任务进行批量编辑

### 3.2 项目与分组管理

#### 3.2.1 项目管理
- **项目 CRUD**: 创建、编辑、删除、归档项目
- **项目设置**: 自定义颜色、图标、描述
- **项目统计**: 任务完成率、进度跟踪

#### 3.2.2 分组功能
- **灵活分组**: 自定义分组规则
- **分组视图**: 按分组展示任务
- **分组统计**: 各分组的任务分析

### 3.3 标签与过滤系统

#### 3.3.1 标签管理
- **多标签**: 每个任务支持多个标签
- **标签分类**: 自定义标签颜色和分类
- **标签统计**: 标签使用频率分析

#### 3.3.2 过滤与搜索
- **内置过滤器**: 
  - 今天、本周、下周
  - 即将到期、已过期
  - 已完成、未完成
- **自定义过滤器**: 基于任务属性创建复杂过滤条件
- **全文搜索**: 搜索任务标题、描述、备注
- **智能视图**: 动态筛选和排序

### 3.4 时间管理与提醒

#### 3.4.1 双时间模式支持
- **日历模式**: 
  - 设置具体的开始和结束时间
  - 支持全天事件
  - 时间冲突检测
- **截止日期模式**: 
  - 设置最后期限
  - 支持仅日期或精确时间

#### 3.4.2 提醒系统
- **系统通知**: 集成 macOS 通知中心
- **提醒规则**: 自定义提醒时间
- **重复提醒**: 支持多次提醒设置
- **智能提醒**: 基于任务优先级和时间的智能提醒

## 4. 界面与交互需求

### 4.1 视图模式

#### 4.1.1 列表视图
- **基础列表**: 传统的任务列表展示
- **增强表格**: 表格形式展示任务的各项属性
  - 显示列：任务名称、项目、标签、优先级、截止日期、完成状态、备注
  - 列排序和筛选
  - 列宽度调整和显示/隐藏

#### 4.1.2 甘特图视图
- **项目时间线**: 可视化项目进度
- **任务依赖**: 显示任务间的依赖关系
- **拖拽调整**: 直接拖拽调整任务时间
- **资源视图**: 显示任务分配情况

#### 4.1.3 仪表盘
- **任务统计**: 完成率、待办数量、过期任务
- **项目概览**: 各项目进度一览
- **时间分析**: 任务完成趋势图
- **效率指标**: 个人生产力分析

### 4.2 导航结构

#### 4.2.1 侧边栏
- **项目列表**: 显示所有项目及任务数量
- **内置视图**: 今天、本周、即将到期等
- **自定义过滤器**: 用户创建的筛选条件
- **标签快速访问**: 常用标签快捷入口

#### 4.2.2 主界面
- **任务列表**: 当前选中项目/视图的任务
- **工具栏**: 视图切换、排序、筛选、操作按钮
- **状态栏**: 显示当前视图统计信息

### 4.3 主题与个性化

#### 4.3.1 主题系统
- **自动主题**: 跟随 macOS 系统设置
- **手动选择**: 浅色、深色主题切换
- **自定义配色**: 用户自定义颜色方案
- **预设主题**: 提供多种配色预设

#### 4.3.2 界面定制
- **字体大小**: 可调节界面字体大小
- **布局选项**: 侧边栏宽度、列表密度调节
- **快捷键**: 全局和应用内快捷键自定义

## 5. 非功能需求

### 5.1 性能要求
- **响应时间**: 所有操作响应时间 < 200ms
- **数据容量**: 支持 10,000+ 任务的流畅操作
- **内存使用**: 正常使用下内存占用 < 200MB
- **启动时间**: 应用启动时间 < 3秒

### 5.2 可用性要求
- **界面直观**: 新用户 5分钟内掌握基础操作
- **键盘操作**: 所有功能支持键盘快捷键
- **错误处理**: 友好的错误提示和恢复机制
- **数据安全**: 自动保存，防止数据丢失

### 5.3 跨平台要求

#### 5.3.1 平台支持
- **第一阶段**: macOS (10.15+)
- **第二阶段**: Windows (10+)
- **未来扩展**: Linux (Ubuntu, Fedora)

#### 5.3.2 系统集成
- **通知中心**: 原生系统通知
- **全局快捷键**: 系统级快捷键支持
- **菜单栏/系统托盘**: 后台常驻运行
- **开机自启动**: 可选的自启动功能
- **窗口管理**: 最小化到托盘、窗口置顶、状态记忆

### 5.4 多语言支持
- **主要语言**: 英文 (默认)
- **次要语言**: 中文简体、日文
- **本地化范围**: 界面文本完全本地化
- **日期格式**: 提供长短两种格式，遵循系统设置
- **语言切换**: 实时切换，无需重启

## 6. 数据存储与同步

### 6.1 存储架构

#### 6.1.1 分层存储
- **热数据库** (`hot_data.db`):
  - 活跃任务 (未完成 + 最近3个月内的已完成任务)
  - 活跃项目和用户设置
  - 缓存和索引表
- **冷数据库** (`cold_data.db`):
  - 历史已完成任务 (>3个月)
  - 归档项目和历史统计数据

#### 6.1.2 数据路径配置
- **默认路径**:
  - macOS: `~/Library/Application Support/uletodo/`
  - Windows: `%AppData%/uletodo/`
  - Linux: `~/.local/share/uletodo/`
- **自定义路径**: 用户可设置存储位置，支持云盘同步

### 6.2 数据同步

#### 6.2.1 iCloud Drive 同步
- **文件同步**: 通过 iCloud Drive 等文件同步服务
- **冲突处理**: 检测并提供冲突解决界面
- **备份快照**: 自动创建数据快照便于回滚

#### 6.2.2 协作预留
- **数据库字段预留**:
  - `remote_id`: 远程协作 ID
  - `owner_id`: 任务所有者
  - `assignee_id`: 任务分配者
  - `version`: 数据版本号
  - `updated_at`: 最后更新时间
  - `dirty`: 本地修改标记

### 6.3 用户管理
- **本地用户**: 创建本地用户身份，无需网络账号
- **用户设置**: 个人偏好、主题、语言等设置
- **数据隔离**: 支持多用户数据隔离
